# Module 4 — Infrastructure d'envoi

**Statut : structure seulement. L'envoi réel d'emails n'est PAS encore codé.**

## Ce que fera ce module (plus tard)

Gestion de l'envoi d'emails avec une attention particulière à la
délivrabilité (réputation domaine/IP, limites de volume, espacement des
envois). C'est le module le plus délicat de la chaîne : il sera construit
en dernier, juste avant le module de reporting, une fois que les modules 1
à 3 et 5 tournent correctement.

## Pourquoi ce dossier est vide pour l'instant

Pour éviter tout envoi accidentel ou mal configuré pendant que le reste du
système est encore en construction.
