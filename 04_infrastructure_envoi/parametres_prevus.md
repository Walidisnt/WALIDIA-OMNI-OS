# Paramètres prévus pour le module 4 (non codés, à valider avant implémentation)

Cette liste sert de mémo pour la session où ce module sera réellement
codé. Aucun de ces paramètres n'est actif aujourd'hui.

| Paramètre | Description |
|---|---|
| `domaine_envoi` | Domaine dédié à l'outreach (jamais le domaine principal) |
| `limite_quotidienne` | Nombre max d'emails envoyés par jour et par boîte |
| `delai_entre_envois` | Espacement aléatoire entre deux envois (secondes) |
| `respect_opt_out` | Vérification obligatoire du champ `opt_out` du CRM avant tout envoi |
| `respect_bloctel` | Vérification obligatoire de `bloctel_verifie` avant tout appel téléphonique |
| `fournisseur_smtp` | Fournisseur SMTP retenu (à choisir avec l'utilisateur) |
| `warmup_ip_domaine` | Plan de montée en charge progressive du domaine/IP |
