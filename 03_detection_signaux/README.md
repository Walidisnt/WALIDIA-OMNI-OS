# Module 3 — Détection de signaux

**Statut : pas commencé.**

## Ce que fera ce module

Pour une liste d'entreprises, recherche des signaux d'achat (recrutements
IA/data, actualités pertinentes) pouvant indiquer un bon moment pour
prospecter.

## Entrée prévue

CSV ou liste d'entreprises (nom, secteur, site web).

## Sortie prévue

CSV des entreprises avec les signaux détectés et leur date.
